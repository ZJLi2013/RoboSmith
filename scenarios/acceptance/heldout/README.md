## F5 `f5_clutter`

- **约束：** 两道矮墙（`wall_01`，一道转 45°、一道转 90°）围着 die，die 也转 45°；手指垂直于近墙会在下探时撞墙。
- **难度参数：** die 到近墙（`wall_a`）的间隙。生成前固定 die 在 `wall_a` 局部系的偏移（x −0.075 至 −0.04 m，
  y −0.10 至 0.10 m），test 100–119 的实际间隙 5.7–38.9 mm。
- **为什么在新版动作域内：** 只用俯抓，抓取朝向平行于近墙即可，不需要推、侧抓或侧插；复用已准入的 `wall_01`。
- **见证与对照**（`witness.json`）：见证俯抓转 45°、搬运高度 0.20 m；受限对照转 135°（手指垂直于近墙），
  seed 100–101 都在 descend 段 `left_finger-wall_a` 违规。
- **没选的候选：** 垫上横梁，没有已准入的横梁资产，要先走准入；先推再抓，需要 `push`，在新版第一版动作域外。
- **局限：** 它是固定两墙的布局，不是数量随机的杂物。
